# 雨世界蛞蝓猫基础数值整理

本仓库整理了《雨世界》（Rain World）及其 DLC 中，各蛞蝓猫角色的基础数值，包括食物、移动、投掷、潜行、游泳等属性，方便玩家查阅、对比和 Mod 参考。

> 本资料为非官方玩家整理，仅供学习、研究与交流使用。  
> 《雨世界》游戏及相关内容的版权归 Videocult 所有。

## 三、数据来源

本资料主要来源如下：

1. 使用 **dnSpy** 对游戏文件 `Assembly-CSharp.dll` 进行反编译，读取 `SlugcatStats`、`Player.ThrownSpear` 等类与方法中的数值逻辑。
2. 部分数值会因游戏版本、DLC、Remix 选项不同而略有差异。

> 注意：本仓库不包含任何游戏本体、DLL 文件、完整反编译源码或受版权保护的原始资源。

---

## 四、使用方法

1. 直接下载 `.xlsx` 文件，用 Excel、WPS 或 LibreOffice 打开。

2. 表格中的“伤害加成”是 `spearDamageBonus`，不是最终伤害。  
   最终伤害还要乘上矛的基础伤害、命中部位、生物护甲等修正。
   
---

## 五、数值说明

- **跑动速度倍率**：不是最终速度，还要乘上游戏内部的基础速度。
- **投掷技能等级**：0、1、2，分别影响投矛伤害与投掷表现。
- **投矛伤害加成**：白猫默认 1.0，黄猫约 0.6~0.9，红猫 1.25，饕餮 3.0 但力竭后 0.3。
- **向上投矛**：需要开启更多蛞蝓猫内容中的相关选项，伤害加成固定为 0.8。
